# 奖项资料怎么进库

检索和写库分开。能上网的 AI，或本机的 Wikidata 拉取，都只产生一份 JSON。整理脚本再写入奖项笔记，并在 `影片/` 按检索名建立影片骨架。

奖项只更新这六篇：奥斯卡金像奖、金球奖、英国电影学院奖、戛纳电影节、威尼斯电影节、柏林电影节。影片骨架只填中文名、上映年、检索名，有原名再补原名。观影评分、观影笔记和电影分析保持原样。

## 两条来源

1. **Wikidata（奥斯卡）**。适合整届获奖和提名。

```bat
工具\拉取奥斯卡.bat --year 1998 --category 最佳影片
```

连不上时，脚本把填好任务的提示词写到 `收件箱/待检索/`。把那段提示词交给能搜索的 AI，再把返回的 JSON 放进 `收件箱/`。

2. **能搜索的 AI**。也可以直接用 `工具/prompts/检索-奖项.md`。JSON 存到 `收件箱/`，例如 `收件箱/金球奖-1998.json`。

## 预览和写入

```bat
工具\预览导入.bat 收件箱\2.json
工具\执行导入.bat 收件箱\2.json
```

预览只生成 `收件箱/预览-*.md`。执行会更新奖项表，并新建 `影片/检索名.md`。库根下同名的空笔记会被删掉，避免和 `影片/` 里的笔记重名。

待核如果涉及检索名、奖项名、结果或中文名，执行也会停在预览。只涉及具体上映日的待核会留在报告里，不写入影片笔记。只要文字、不要图片时：

```bat
.\.venv\Scripts\python.exe 工具\import_packet.py 收件箱\示例-奥斯卡1998-最佳影片.json --apply --no-images
```

同一条记录再执行一次会跳过，不会重复追加。以 `#` 开头的 Chronos 示例行会保留。

## 按模板整理影片

```bat
.\.venv\Scripts\python.exe 工具\整理影片.py
.\.venv\Scripts\python.exe 工具\整理影片.py "翼 (1927)" "第七天堂 (1927)" "非法图利 (1928)"
```

不写片名时，处理 `影片/` 里除索引以外的全部笔记。结构按 `模板/影片.md` 重排，已填写的文首属性和手写的简介、分析、观影笔记会留下。

## 图片分类

| 角色 | 文件夹 | 文件名 |
| --- | --- | --- |
| 标识、典礼 | `附件/奖项/检索名/` | `标识.jpg`、`典礼-1998.jpg` |
| 海报、画面 | `附件/影片/检索名/` | `海报.jpg`、`画面-01.jpg` |
| 照片 | `附件/人物/检索名/` | `照片.jpg` |

扩展名按实际文件，可以是 jpg、png、webp、gif。奖项导入只从这三个地址下载：`upload.wikimedia.org`、`commons.wikimedia.org`、`image.tmdb.org`。豆瓣影片导入另外允许 `img*.doubanio.com` 的海报。

手贴图片时安装社区插件 **Custom Attachment Location**，把新附件位置设为：

```text
附件/${noteFolderName}/${noteFileName}
```

不要在开头加 `./`。这样在奖项笔记里粘贴的图片会进 `附件/奖项/笔记名/`，影片和人物笔记同理。插件不能区分「这张是海报还是标识」，固定文件名仍由入库程序负责，所以不需要再写一个插件。

## 豆瓣影片

列表来自豆瓣的年份、地区、类型筛选，不是该年全部电影。默认先预览。拉列表前必须已登录：在浏览器打开豆瓣电影并登录，把该页请求头里的整行 Cookie 存成 `工具/douban_cookie.txt`。其中要有 `dbcl2`。没有登录态时脚本不会发列表请求。该文件不进 git。

```bat
.\.venv\Scripts\python.exe 工具\fetch_douban_list.py --year 1927 --region 美国
.\.venv\Scripts\python.exe 工具\fetch_douban_detail.py --list 收件箱\豆瓣\列表-1927-美国-全部.json --threads 2
.\.venv\Scripts\python.exe 工具\import_douban_films.py --list 收件箱\豆瓣\列表-1927-美国-全部.json
.\.venv\Scripts\python.exe 工具\import_douban_films.py --list 收件箱\豆瓣\列表-1927-美国-全部.json --apply
```

`--threads` 最大 5，默认 2。遇到验证、拒绝访问或页面标题为「禁止访问」会立即停止，不要马上重试。`--apply` 只落库已经有详情的影片，没有详情的编号写在 `收件箱/豆瓣/缺少详情-*.log`。已有笔记如果没有空字段可填，不改这个文件。同名笔记的豆瓣编号不同时不覆盖。我的评分、观影记录、电影分析和观影笔记保持原样。豆瓣评分只写在预览里。

人物从已有影片的豆瓣条目来。用一条流水线即可：影片条目返回后马上抓其中的人物，人物页优先于还没开始的影片，全进程共用一个间隔。请求返回的新 Cookie 会立刻写回 `工具/douban_cookie.txt`，下次请求先读这份最新 Cookie。每条请求会打印结果，以及还没开始的影片和人物数量。网络阶段结束或被拒绝后才落库。默认只写预览，`--apply` 才写 `人物/` 笔记，并把影片的导演、编剧、主演改成人物链接。角色名先不填。影片只补仍然空着的字段。下面三条命令仍可分开跑。

```bat
.\.venv\Scripts\python.exe 工具\run_douban_pipeline.py --threads 2 --delay 3
.\.venv\Scripts\python.exe 工具\run_douban_pipeline.py --threads 2 --delay 3 --apply
.\.venv\Scripts\python.exe 工具\fetch_douban_credits.py --threads 2 --delay 3
.\.venv\Scripts\python.exe 工具\fetch_douban_people.py --threads 2 --delay 3
.\.venv\Scripts\python.exe 工具\import_douban_people.py --apply
```

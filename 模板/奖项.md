## 时间线

奖项沿革写在时间线前部。影片按颁奖年份追加：获奖用 `#yellow`，提名用 `#blue`，花括号里写具体奖名。

```chronos
> ORDERBY start
> NOTODAY
> DEFAULTVIEW 1920|2027

# = [1929] 首届颁奖
# - [1998] #yellow {最佳影片} [[泰坦尼克号 (1997)]] | 获奖
# - [1998] #blue {最佳影片} [[某片 (1997)]] | 提名
# - [1998] #yellow {最佳男主角} [[泰坦尼克号 (1997)]] [[莱昂纳多·迪卡普里奥]] | 获奖
```
